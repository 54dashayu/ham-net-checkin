HAM Net Check-in Console User Manual

Applies to: V1.04

This manual covers operation. Use the official download page for packages, checksums, and release information.

1. Quick Start

  1. Enter activity and net-control information, then refresh a monitor source.
  2. Click a recent station to queue it; double-click its card to query its profile and enter it.
  3. Review the fields and click Add Record, or use the Enter-key workflow.
  4. Drag a row handle to reorder records, then export Excel or ADIF.

2. Logged Count and Current Serial

  • The card shows logged count in small text and current serial as a large green number.
  • Click the card and enter the number already logged; entering 40 starts at 41.
  • If an existing serial is higher, the next serial follows that maximum.

3. Entry Fields and Defaults

  • Antenna defaults to Stock, power to L, and report to 59. Mode has no default.
  • Enter-key entry carries current defaults but does not fill mode.
  • Lower suggestion menus open upward; Antenna and Notes use equal widths.

Antenna Database Search

  • Suggestions come from the current callsign profile and all local history.
  • Partial text performs fuzzy matching.
  • The full list opens even while the Stock default is present.
  • Built-in Stock, Mobile, GP, and Yagi values are merged with custom history.

4. FMO Candidate Queue

  • A single click only queues a monitor candidate.
  • Double-clicking queries and merges the profile, moves it into the form, and removes the card.
  • Cards omit the pending-entry label and can be cleared individually or together.

5. Logged Records and Drag Reordering

  • Click a row to edit it; search filters callsign, QTH, device, or notes.
  • Hold the far-left handle and drop the row at the required position.
  • Serials are reassigned continuously and the top counter is updated.
  • Excel and ADIF follow the adjusted serial order.

6. Monitor Sources and Web Limitations

FMO, MMDVM, HAMBOX, BrandMeister, YSF, and D-Star are supported as shown. The web edition needs the browser bridge and approved access for local devices; desktop can access them directly.

7. Save and Export

  • Enable Auto Save before a formal net and save manually during long activities.
  • Manual Excel export can include or omit Antenna, Power, and Mode; Auto Save retains all columns.
  • Review serials, callsigns, timestamps, and exports at the end.
