HAM 台网点名主控台使用说明

适用版本：V1.04

本说明书介绍软件操作；下载、校验和发布信息请以正式下载页为准。

1. 快速开始

  1. 填写活动名称和主控台信息，选择并刷新监听源。
  2. 单击最近通联加入备选区；双击备选卡片进入录入区并查询呼号资料。
  3. 检查资料后点击“添加记录”，也可使用回车快捷录入。
  4. 需要调整次序时拖动记录左侧手柄，活动结束后导出 Excel 或 ADIF。

2. 已记录条数与当前序号

  • 顶部以小字显示已记录条数，以大号绿色数字显示当前序号。
  • 点击计数卡片填写“已记录多少条”；例如填写 40，保存后当前序号自动变为 41。
  • 若已有记录序号更大，软件从最大已有序号的下一条开始，避免重复。

3. 录入字段与默认值

  • 天线默认“原装”，功率默认“L”，信号报告默认“59”；模式不设置默认值。
  • 回车快捷录入会带入当前默认值，但不会自动填写模式。
  • 模式、功率、信号报告和天线候选向上展开，避免被列表遮挡。
  • 天线与备注按 1:1 等宽排列。

天线数据库检索

  • 候选来自当前呼号档案和全部本地历史记录。
  • 支持部分文字模糊检索，例如输入“车”可匹配“车载”。
  • 默认显示“原装”时，点击输入框仍会打开完整候选库。
  • 内置“原装、车载、GP、八木”，并合并历史自定义名称。

4. FMO 备选流程

  • 单击监听候选只加入备选区，不立即查询资料库。
  • 双击备选卡片后才带入录入区、查询并合并资料，同时移除卡片。
  • 卡片不显示“待录入”文字；单卡或整个备选区均可用 X 清除。

5. 已记录列表与拖动排序

  • 点击记录行可编辑；搜索可按呼号、QTH、设备或备注过滤。
  • 按住每行最左侧手柄，上下拖动并放到目标位置。
  • 放下后按新顺序重新连续编号，顶部计数和当前序号同步更新。
  • Excel 和 ADIF 按调整后的序号顺序导出。

6. 监听源与网页版限制

支持 FMO、MMDVM、HAMBOX、BrandMeister、YSF 和 D-Star 等来源。网页版访问本地设备需要浏览器插件和审核通过的访问权限；桌面版可直接访问本地设备。

7. 保存与导出

  • 正式点名前建议开启自动保存，长时间活动中定期手动保存。
  • 手动 Excel 导出可选择天线、功率和模式列；自动保存保留全部列。
  • 活动结束后检查序号、呼号、时间和导出文件。
