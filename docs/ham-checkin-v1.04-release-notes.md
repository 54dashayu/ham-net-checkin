# HAM 台网点名主控台 V1.04

## 本次更新

- 修复左侧录入区下方下拉菜单被已记录列表遮挡的问题；模式、功率、信号报告和天线候选改为向上展开。
- 天线默认“原装”、功率默认“L”、信号报告默认“59”；模式保持空白。回车快捷录入会带入当前默认值。
- 天线输入支持从当前呼号档案及全部历史数据库模糊检索，并提供原装、车载、GP、八木内置候选。
- 天线与备注输入区调整为 1:1 等宽。
- 顶部状态卡改为小号“已记录”条数和大号绿色“当前序号”。点击可直接设置已记录条数，当前序号自动从下一条开始。
- 已记录列表新增拖动手柄；放下后按新顺序连续编号，顶部序号及 Excel / ADIF 导出顺序同步更新。
- 新增 V1.04 中英文完整使用说明。

## 继承变化

- V1.03：FMO 单击只加入备选，双击后才查询并合并资料；备选卡片不显示“待录入”；网络版本地设备提示更明确。
- V1.02.1：稳定序号、跳号和手动 Excel 列选择。
