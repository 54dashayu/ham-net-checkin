# HAM 台网点名主控台 V1.02.1

V1.02.1 是基于 V1.02 WebView / VPS 正式基线的小版本修复。

## 用户可见变化

- 每条点名记录保存独立序号。
- 删除记录后，其他记录不再被强制重新连续编号。
- 可把“下一条序号”直接设为 27；已有记录停在 23 时，24–26 可以留空。
- 手动点击工具栏 Excel 按钮时，可选择本次是否包含“天线”“功率”“模式”列。
- 自动保存及服务器保存的 Excel 仍包含全部原有列。

## 兼容与迁移

- 旧版记录首次载入时会按原起始序号补齐稳定序号。
- JSON 备份导入兼容旧记录，并保留已有有效序号。
- V1.02 保留为回退版本。

## 已知边界

- 已被现有记录使用的序号不能再次指定，避免出现重复编号。
- macOS 与 Win64 桌面版继续使用 Tauri 系统 WebView，不捆绑 Chromium。
