## P1：输入框备选下拉菜单难以选中

### 现象

在 Win64 版本和网页版本中，填写设备等部分字段后会出现备选下拉菜单，但存在以下问题：

- 鼠标点击备选项时不容易选中。
- 选中后内容有时没有进入对应填写框。
- 用户需要反复点击或重新输入，影响快速录入。

### 影响范围

- Win64 桌面版。
- 网页版。
- macOS 桌面版：待确认。
- 已观察到的字段包括“设备”等会触发历史/候选下拉的输入框；后续需要逐项确认 QTH、天线、功率、模式、备注等字段是否也受影响。

### 初步判断

该问题可能与输入框失焦、候选菜单点击事件顺序、菜单层级遮挡、鼠标按下与输入框 blur 的触发先后有关。需要重点检查候选菜单的 `mousedown/click` 处理、输入框 blur 延迟、候选项写入状态以及桌面壳/浏览器下事件差异。

### 待补充复现步骤

1. 打开 Win64 版或网页版。
2. 在“设备”等字段输入已有历史内容的前几个字。
3. 等待候选下拉菜单出现。
4. 点击候选项。
5. 观察候选项是否稳定写入输入框。

### 验收标准

- 候选项出现后，单击一次即可稳定写入对应输入框。
- 点击候选项时不会被输入框失焦提前关闭。
- Win64 版和网页版表现一致。

### 处理记录

- 2026-07-09：已将主录入表单和记录编辑弹窗中的 QTH、设备、天线、模式、功率、信号字段从原生 `datalist` 改为自定义候选菜单；候选项使用鼠标按下事件先写入字段，再关闭菜单，用于规避输入框失焦导致候选选择丢失的问题。

## P1：整体输入和按钮操作反应迟钝

### 现象

所有填写框内输入、点击“添加记录”按钮等操作，都有明显反应迟钝的感觉。

### 影响范围

- 输入框打字、清空、选择候选项。
- 点击“添加记录”按钮。
- 已观察到会影响 Win64 桌面版和网页版的整体录入节奏。
- macOS 桌面版：待确认。

### 初步判断

该问题可能与输入时触发过多同步计算、历史候选过滤、呼号资料库匹配、localStorage 写入、自动保存、监听列表刷新或全量响应式更新有关。需要用浏览器 Performance 或临时日志确认卡顿发生在输入事件、渲染、数据持久化还是网络/监听刷新。

### 待补充排查方向

- 输入字段是否每次按键都触发全量记录/资料库搜索。
- 候选列表过滤是否遍历过多历史记录或资料库数据。
- `localStorage`/文件保存是否在每次输入时同步执行。
- “添加记录”是否触发重复记录检查、资料库写入、记录列表排序、自动保存和 UI 重新渲染的连锁更新。
- 自动刷新监听源是否与录入操作争抢主线程。

### 验收标准

- 常规输入无明显卡顿，按键反馈接近即时。
- 点击“添加记录”后记录能快速进入列表，按钮状态无明显停顿。
- 在 Win64 桌面版和网页版中均保持稳定响应。

### 处理记录

- 2026-07-09：已将记录、呼号资料库、同步配置、监听配置和活动配置的本地持久化改为短延迟批量写入，减少输入和点击过程中同步 `localStorage` 写入造成的主线程阻塞。

## 后续处理建议

1. 先复现并录屏确认两个问题是否在同一批输入组件上发生。
2. 优先修复候选下拉菜单点击写入问题，因为它直接影响录入准确性。
3. 再做性能剖析，定位输入延迟来源，避免盲目重构。
4. 修复后分别在网页版、Win64 版和 macOS 本地版做同一套录入回归测试。
