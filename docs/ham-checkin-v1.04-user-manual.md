# HAM 台网点名主控台使用说明

适用版本：V1.04

## 1. 软件用途

HAM 台网点名主控台用于业余无线电台网点名。主控可在一个界面中完成活动信息设置、友台呼号登记、监听源候选读取、资料辅助补全、记录排序以及 Excel / ADIF 日志导出。

## 2. 快速开始

1. 在顶部填写台网活动名称和主控台信息。
2. 在右侧选择监听源，填写地址或通话组并刷新。
3. 单击最近通联可加入备选区；双击备选卡片可进入录入区并查询呼号资料。
4. 检查 QTH、设备、天线、功率、模式、信号报告和备注。
5. 点击“添加记录”，或在呼号录入流程中使用回车快捷录入。
6. 如需调整次序，拖动已记录列表左侧的手柄。
7. 活动结束后导出 Excel 或 ADIF。

## 3. 顶部活动栏与序号

- 顶部显示小号“已记录”条数和大号绿色“当前序号”。
- 点击计数卡片可填写“已记录多少条”；保存后，当前序号自动从下一条开始。例如填写 40，当前序号变为 41。
- 如果已有记录的序号更大，软件会从最大已有序号的下一条开始，避免重复。
- 保存、自动保存和新建分别用于保存当前活动、自动保存变更和开始新活动。

## 4. 添加记录与默认值

- 呼号为必填，支持自动大写和呼号候选。
- QTH、设备、模式、功率、信号报告、天线和备注按实际通联情况填写。
- 天线默认值为“原装”，功率默认值为“L”，信号报告默认值为“59”；模式不设置默认值。
- 回车快捷录入会带入当前默认值，包括“原装”“L”和“59”，但不会自动填写模式。
- 下方的模式、功率、信号报告和天线候选菜单向上展开，避免被已记录列表遮挡。
- 天线与备注在录入区按 1:1 等宽显示，便于查看完整天线名称。

### 4.1 天线资料检索

- 天线输入框会从当前呼号档案和全部历史记录中读取候选。
- 输入部分文字可模糊检索，例如输入“车”可匹配“车载”。
- 默认显示“原装”时，点击输入框仍会打开天线候选库。
- 内置候选包括“原装、车载、GP、八木”，并会合并历史录入的自定义天线名称。

### 4.2 FMO 备选区

- 单击右侧监听候选只加入备选区，不立即查询呼号资料库。
- 双击备选卡片后才会把呼号带入录入区、查询并合并资料，然后移除该卡片。
- 备选卡片不显示“待录入”文字；右上角 X 可删除单张卡片，备选区右上角 X 可清空全部。

## 5. 监听源

- FMO：填写 FMO 地址并选择 ws 或 wss。
- MMDVM：读取 Last Heard，可选择全部、TS1 或 TS2。
- HAMBOX：读取最近通联。
- BM DMR：填写 BrandMeister 通话组。
- YSF、D-Star 等网络来源按界面提示使用。
- 网页版访问本地 FMO、MMDVM 或 HAMBOX 时，需要浏览器插件和审核通过的本地设备访问权限；桌面版可直接访问本地设备。

## 6. 已记录列表与拖动排序

- 搜索框可按呼号、QTH、设备或备注过滤记录。
- 点击记录行可打开编辑窗口。
- 按住每行最左侧的拖动手柄，上下移动并放下即可改变顺序。
- 拖动完成后，软件会按新顺序重新连续编号，并同步顶部计数和当前序号。
- Excel 和 ADIF 会按调整后的序号顺序导出。
- 全选、取消和删除选中可用于批量管理记录。

## 7. 保存与导出

- 正式点名前建议开启自动保存，并在长时间活动中定期手动保存。
- Excel 手动导出可选择是否包含天线、功率和模式；自动保存保留全部列。
- ADIF 用于导入兼容的业余无线电日志软件。
- 活动结束后应检查序号、呼号、时间和导出文件是否完整。

## 8. 常见操作

- 设置已记录条数：点击顶部计数卡片。
- 调整记录顺序：拖动记录行左侧手柄。
- 修改已有记录：点击该记录行。
- 清空单个字段：点击输入框右侧 X。
- 查看说明书或切换语言：使用右上角说明书和语言图标。
