# HAM 台网点名主控台 V1.01.1 Web-first 测试版试制说明

状态：已按浏览器插件桥方案试制  
目标版本：V1.01.1 测试版  
方向：网页主应用 + Chrome / Edge 浏览器插件桥  
基线版本：V1.0.01

## 1. 背景判断

V1.0.01 已完成 Win64 安装包和 macOS 公证 DMG，但 Electron 桌面包体积偏大：Windows 安装包约 108 MB，macOS DMG 约 220 MB。当前业务代码本身并不大，体积主要来自 Electron 打包携带 Chromium、Node.js 和桌面运行时。

台网点名主控台的核心使用体验更接近网页应用：打开即用、快速登记、监听候选、导出 Excel / ADIF、呼号资料辅助补全。桌面版真正解决的问题主要是本地网络设备访问、离线保存和局域网权限，而不是界面本身必须运行在桌面壳中。

因此 V1.01.1 测试版转为 Web-first 试制：网页版作为主产品形态，桌面包作为兼容方案；本地设备访问不再单独发布代理包，而是通过 Chrome / Edge 浏览器插件桥完成。

## 2. 版本目标

V1.01.1 不再以“继续增大桌面包能力”为主，而是验证以下方向是否可行：

- 网页版成为主入口：`https://fmo.bh1jss.net/checkin/`
- 本地设备访问从 Electron 壳中拆出，改为可选 Chrome / Edge 浏览器插件桥。
- MMDVM / HAMBOX / FMO 的局域网读取能力通过浏览器插件桥试制；公网网页未注册时仍不开放本地设备访问。
- 用户数据仍优先保留在浏览器本地，可导出 Excel / ADIF。
- 桌面安装包保留为本地活动和离线场景的稳定下载。

## 3. 产品形态

### 3.1 网页主应用

网页主应用继续使用现有 Vue 页面，保留 V1.0.01 已完成能力：

- 台网活动信息录入。
- 备选区 4 卡片工作流。
- 右侧最近 6 个呼号高亮。
- MMDVM TS1 / TS2 时隙筛选。
- HAMBOX、BM DMR、FMO 候选源。
- Excel / ADIF 导出。
- 呼号资料库辅助补全。
- 中英文说明书。
- 匿名使用统计提示。

### 3.2 浏览器插件桥

浏览器插件桥只做一件事：让经过授权的网页安全读取用户局域网内的设备数据。公网网页入口默认不开放本地设备访问；如需开放，必须先完成注册并由作者审核通过。

插件提供页面消息接口：

```text
HAM_BRIDGE_PING
HAM_BRIDGE_FETCH
HAM_BRIDGE_WS_OPEN / SEND / CLOSE
```

插件职责：

- 只允许访问局域网或用户显式填写的设备地址。
- 公网网页调用本地设备前必须检查授权状态。
- 增加超时和错误提示。
- 返回标准 JSON 或原始 HTML 解析结果。
- 仅允许 `https://fmo.bh1jss.net/checkin/` 和本地开发地址调用。
- 不保存用户日志，不上传设备数据。

### 3.3 桌面版定位

V1.0.01 Electron 桌面版继续保留，但在 V1.01.1 中定位为：

- 离线环境 fallback。
- 需要完整本地应用体验的用户 fallback。
- 长期活动现场的稳定备选方案。

首页和说明书应把“网页版 + 浏览器插件”作为网络版完整功能路径，并保留 Win64 / macOS 本地版下载。

## 4. V1.01.1 最小试制范围

第一阶段不要做大而全，只验证最关键链路：

1. 网页端增加浏览器插件状态按钮和独立安装说明。
2. 网页端可检测浏览器插件桥是否启用。
3. MMDVM 本地读取优先尝试浏览器插件桥。
4. HAMBOX 本地读取优先尝试浏览器插件桥。
5. 公网网页未通过注册审核时，不允许启用本地代理。
6. 插件未启用时给出清晰提示，而不是直接报连接失败。
7. 保留 Win64 / macOS 本地版作为回退，不删除旧路径。

暂不纳入第一阶段：

- 自动发现局域网设备。
- 插件自动升级。
- 后台常驻托盘。
- Windows 服务安装。
- macOS LaunchAgent 安装。
- 完整设备配置向导。

## 5. 浏览器插件桥实现

### 5.1 Chrome / Edge MV3 插件

优点：

- 用户在 Chrome / Edge 中安装后即可让网页访问本地设备。
- 不需要在页面暴露本地端口。
- 可以同时支持 HTTP 拉取和 WebSocket 转发。

缺点：

- 需要用户开启扩展程序开发者模式并手动加载插件目录。
- Safari 暂不作为第一阶段目标。

### 5.2 本地版保留

优点：

- 不依赖浏览器扩展安装。
- 适合长期活动、离线环境和需要完整本地体验的用户。

缺点：

- 仍需要分别维护 Win64 / macOS 安装包。

V1.01.1 已选择浏览器插件桥作为网络版本地设备访问路径，不再公开旧代理方案。

## 6. 前端改动锚点

建议新增配置项：

```js
localProxyEnabled: true
browserBridgeEnabled: true
```

建议 UI 位置：

- 右上角增加常驻“插件”状态按钮。
- 插件按钮点击后打开独立下载与安装说明。
- 当选择 MMDVM / HAMBOX / FMO 本地源时显示权限或插件检测状态。
- 公网网页未获得作者审核通过时显示“网页版本地设备访问需注册并通过作者审核”。
- 插件在线：按钮变为绿色并显示“插件已连接”。
- 插件离线：提示下载并启用 Chrome / Edge 浏览器插件。

建议数据流：

```text
网页版
  -> 检测浏览器插件桥
  -> 公网入口先检查注册审核状态
  -> 插件在线：通过插件读取 MMDVM/HAMBOX/FMO
  -> 插件离线：使用现有网页能力或提示下载启用
```

## 7. 测试矩阵

| 场景 | 验证内容 | 阻断标准 |
| --- | --- | --- |
| 纯网页 BM DMR | 不安装代理也能打开网页并读取 BM | 网页打不开或 BM 基础流程失败 |
| 公网网页未授权 | 选择 MMDVM/HAMBOX 时提示需注册审核，不能启用代理 | 未授权也能读取局域网设备 |
| 网页 + MMDVM 插件 | `192.168.31.119` Last Heard 可读取，TS1/TS2 筛选有效 | 无法读取或筛选错误 |
| 网页 + HAMBOX 插件 | HAMBOX 最近通联可读取 | 无法读取候选 |
| 插件未启用 | 网页给出清晰提示，不崩溃 | 用户只看到底层网络错误 |
| Excel / ADIF 导出 | 网页端仍可导出 | 文件损坏或字段缺失 |
| macOS 浏览器 | Chrome 访问网页与插件 | 插件不可用且无说明 |
| Windows 浏览器 | Edge / Chrome 访问网页与插件 | 无法连接本地设备 |
